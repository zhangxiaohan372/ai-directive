# 平台 UI 视觉风格与反例红线规范 (UI Style Constitution)

本规范确立了本平台（AI Detective · 智能探案平台）的界面视觉哲学、双主题色彩系统、排版层级、标志性母题、页面级模板，并基于历史开发实践明确列出必须杜绝的**五大负面反例（Anti-Patterns）**与**装饰预算约束**。

---

## 1. 核心设计哲学 (Design Philosophy)

- **智性探案质感 (Analytical Detective Aesthetics)**：界面应传递严谨、理性、古典与沉浸的侦探书房质感，呈现如手工案卷、法医检验单、复古手稿一般的精致度。
- **克制与信息密度**：拒绝空洞的浮夸动画与通用后台组件感，重视信息排布的条理性、物理案卷纸张的触感反馈与纯粹的案情沉浸。

---

## 2. 双主题色彩规范 (Dual Theme Palette)

平台全站支持且必须无缝联动 **白昼手稿 (Light Manuscript)** 与 **暗夜书房 (Dark Study)**：

### 白昼手稿 (Light Manuscript)
- **主背景基底**：`#F5EFE6`（老式羊皮纸暖灰白）/ `#FAF7F2`（卡片白底）
- **主要文字**：`#2C241E`（墨水炭黑，高对比度可读性）
- **次要辅助文字**：`#6E5F52` / `#8C7E72`（铅笔灰褐色）
- **核心品牌强调色**：`#8B3A2B`（火漆印章深朱红）/ `#783023`（悬停深红）
- **边框与分割线**：`#E8DFD5` / `#E0D5C7`（纸张压痕细线）

### 暗夜书房 (Dark Study)
- **主背景基底**：`#0C0A09`（黑曜石深木色）/ `#120F0D`（书桌深木卡片底）
- **主要文字**：`#E5DCD0` / `#F3EFEA`（古籍微黄象牙白）
- **次要辅助文字**：`#8C765E` / `#A89073`（黄铜氧化灰金）
- **核心品牌强调色**：`#C9942D` / `#DFB36C`（古董金、琥珀黄铜）
- **边框与分割线**：`#2C2117` / `#3E2D1E`（深胡桃木边框）

## 3. 五大负面反例红线 (Negative Anti-Patterns & Prohibitions)

以下 5 项是用户明确要求修改并杜绝的反例，任何 UI 代码中**严禁出现**：

### 反例 1：严禁在 UI 中使用任何 Emoji 字符 (Strict Zero-Emoji Rule)
- **错误反例**：在按钮、徽标、提示文字中夹带任何 Emoji 字符。
- **正确规范**：必须统一采用精细矢量线框图标（如 `lucide-vue-next`），图标线宽推荐 1.5 - 1.8px。

### 反例 2：严禁全屏死板纯黑 / 单色死锁 (No Monochrome Pure-Black Lock)
- **错误反例**：子页面强行写死纯黑单色背景，导致点击顶部切换白昼主题时界面没有任何反应。
- **正确规范**：所有页面容器与组件必须联动响应全局 `themeMode` 或 `isDark`。

### 反例 3：严禁摆设无实际交互的悬空废弃按钮 (No Redundant Dummy Buttons)
- **错误反例**：摆放无法点击或点击后无任何响应的冗余演示按钮。
- **正确规范**：没用到的冗余按钮坚决删除；保留的每个按钮都有明确的功能挂载、即时音效（`sound.playPaperRustle()`）与视觉状态反馈。

### 反例 4：严禁各级子页面顶部栏割裂不一致 (Unified Header Standard)
- **错误反例**：各级子页面、弹窗各搞一套自定义角标或缺失导航工具。
- **正确规范**：全站所有模块（首页、工作台、探案游戏、登录验证页）的顶栏必须保持完全一致的品牌头结构：
  1. 左侧：品牌 Logo + `AI DETECTIVE · 智能探案平台` + 当前模块面包屑。
  2. 右侧：白昼/暗夜分段切换开关 + 音效静音按钮 + 侦探头像/关闭入口。

### 反例 5：严禁浮夸的 AI 科技感霓虹光晕 (No Neon AI Slop)
- **错误反例**：滥用荧光紫/青光晕、发光大胶囊、彩虹渐变边框。
- **正确规范**：采用典雅的微边框、物理纸纹与书卷圆角、复古衬线排版与真实的按压微阴影。

## 4. 标志性三大视觉母题 (Signature Motifs)

为确立平台的侦探物证触感，界面设计必须规范使用以下三大核心母题：

### 母题 1：火漆印章 (Wax Seal Stamp)
- **使用位置**：核心案卷卡片左上角（或右上角）、结案通关证书、绝密证据核验单、401 权限失效封印。
- **实现规范**：
  - 双层微凹凸圆形物理印章，微倾斜角度（`-rotate-6` 至 `-rotate-12`），外圈带有压痕纹理与柔和投影（`shadow-lg`）。
  - 内圈微缩圆环，中心镌刻粗衬线单个汉字（如“密”、“核”、“卷”）。
  - 色彩对应：白昼手稿采用火漆深朱红（`#8B3A2B`，边框 `#A34333`，字色 `#FDF0EE`）；暗夜书房采用琥珀深红或古铜金火漆（`#A33B2B` 或 `#C9942D`）。

### 母题 2：纸张压痕与微凹双线 (Paper Crease & Deboss Line)
- **使用位置**：卡片内部段落分割、档案表头分隔、输入框底边线、面板折叠边缘。
- **实现规范**：
  - 严禁使用生硬突兀的 1px 黑色或深灰色实线。
  - 采用物理折痕微压阴影：白昼主题使用浅色微凸纸痕（`border-t border-[#E8DFD5] shadow-[0_1px_0_rgba(255,255,255,0.8)]`）；暗夜主题使用深木刻槽线（`border-t border-[#2C2117] shadow-[0_1px_0_rgba(255,255,255,0.03)]`）。

### 母题 3：案卷标签页 (Folder Tab & Dossier Ear)
- **使用位置**：案卷纸模态框、档案抽屉、分类卡片顶部。
- **实现规范**：
  - 模拟物理马尼拉纸案卷袋顶部突出的索引标签耳。
  - 从卡片顶部边缘向上凸起 28px-32px，左右带有柔和倒角（`rounded-t-xl border-t border-x`），内嵌档案类别或编号文本（如 `【案卷分类：绝密调阅单】`），与卡片背景同色一体成型。

## 5. 页面级标准模板与线框规范 (Page-level Wireframe Templates)

### 模板 1：登录页（案卷纸验证单 Dossier Auth Page）
- **尺寸与排版**：卡片放大 15–20% 至 `max-w-[560px]`（居中呈现于午夜书桌背景之上）。
- **线框结构**：
  ```
  +---------------------------------------------------------------+
  | [顶栏] Logo + AI DETECTIVE · 智能探案平台    [白昼/暗夜] [音效] [X] |
  +---------------------------------------------------------------+
                 | [标签页] 绝密案卷 · 调阅审批单 |
  +--------------+-------------------------------+----------------+
  | (火漆印章)                                                    |
  | 主标题：侦探档案调阅核验                                       |
  | 副标题：请核验警务印信口令以调阅本案卷宗 (401 时替换为朱红警报条)  |
  | ------------------------------------------------------------- |
  | 字段一：侦探警号 (纯中文标签 + 纸纹内凹输入框)                   |
  | 字段二：印信口令 (纯中文标签 + 密码输入框)                       |
  | [x] 保持 30 天登录状态                                        |

  +---------------------------------------------------------------+
  ```

### 模板 2：首页（案桌与大厅 Home Portal）
- **尺寸与排版**：`max-w-[1440px]` 响应式栅格，顶部 64px 统一品牌头，紧接 540-620px 高度的大景深探案书桌横幅。
- **线框结构**：
  ```
  +---------------------------------------------------------------+
  | [顶栏] Logo + 智能探案平台    [搜索] [白昼/暗夜] [音效] [侦探身份印章] |

  +---------------------------------------------------------------+
  ```

- **尺寸与排版**：标准宽度 `320px - 360px`，圆角 `rounded-2xl`，内距 `p-4`。
- **线框结构**：

## 6. 装饰预算与字号下限约束 (Decoration Budget & Typographic Constraints)

为杜绝界面沦为“无意义文字堆砌”或“视觉垃圾”，必须严格遵守以下硬性约束：

1. **装饰性英文预算清零 (Zero Decorative English Junk)**：
   - 严禁使用任何无业务含义的“假科技感/假警务”英文小字堆叠（严禁出现 `CID DOSSIER CLEARANCE`, `FILE: SEC-8492`, `AUTH-GATEWAY`, `SCOTLAND-YARD ENCRYPTION SHA-256`, `BADGE ID`, `PASSCODE` 等）。
   - 除全站专有品牌名 `AI DETECTIVE` 允许出现外，所有界面字段名、状态说明、辅助描述必须一律使用纯中文。
2. **等宽字（font-mono）预算**：
   - 等宽字仅允许用于真实的**案件编号**（如 `NO.8492`）、**时间戳**（如 `22:15`）与**统计百分比**（如 `100%`）。
   - **每屏界面中出现的等宽字体标签不得超过 3 处**。
3. **字号下限 (Typographic Minimums)**：
   - 正文与表单提示文字最小不得低于 `12px` (`text-xs`)，严禁出现 8px~10px 的视觉垃圾字号。
   - 主标题不得低于 `20px` (`text-xl`)，卡片标题不得低于 `16px` (`text-base`)。
4. **色彩对比度下限 (WCAG AA Contrast >= 4.5:1)**：
   - 严禁在浅色背景上使用浅灰色文字，严禁在深色背景上使用低对比度暗灰。
   - 白昼手稿主题主文字必须使用墨水炭黑 `#2C241E`（对比度 > 11:1），次要文字不低于 `#6E5F52`（对比度 > 4.6:1）。
   - 暗夜书房主题主文字必须使用象牙白 `#F3EFEA`（对比度 > 13:1），次要文字不低于 `#A89073`（对比度 > 5:1）。
